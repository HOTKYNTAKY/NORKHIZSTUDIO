# VORTEXNET — فروشگاه اشتراک

سایت فروش فارسی و راست‌چین VORTEXNET با طراحی واکنش‌گرا، تعرفه‌ها و محاسبه‌گر حجم، انیمیشن‌های سبک‌شونده و پنل/بک‌اند self-hosted در پوشه‌ی `server/`.

## ساخت سایت برای GitHub Pages

این مخزن در حال حاضر از GitHub Pages روی `main:/` استفاده می‌کند. سورس قابل نگهداری داخل `app/` است؛ برای ساخت و کپی خروجی استاتیک به ریشه‌ی مخزن:

```bash
npm ci
npm run publish:pages
```

سپس تغییرات پوشه‌ی `app/` و فایل‌های خروجی ریشه (به‌خصوص `index.html` و `assets/`) را commit و به `main` برسان. دامنه‌ی `vortexnett.shop` با `CNAME` ثبت شده است.

## نکته‌ی مهم درباره‌ی خرید واقعی

GitHub Pages فقط فایل استاتیک میزبانی می‌کند و نمی‌تواند Node API، ثبت سفارش، حساب مشتری، پنل ادمین یا اتصال PasarGuard را اجرا کند. تا وقتی بک‌اند در یک سرور امن راه‌اندازی نشده باشد، قیمت‌ها و محاسبه‌گر صفحه کار می‌کنند اما پرداخت و ثبت سفارش عمداً غیرفعال می‌مانند.

کد بک‌اند، تنظیم Nginx و نصب‌کننده‌ی سرور در `server/`, `deploy/` و `install.sh` قرار دارند. این فایل‌ها در این مخزن اجرا نشده‌اند. برای فروش واقعی، بک‌اند باید روی VPS امن نصب شود و مسیر `/api` سایت به آن متصل گردد. چون دامنه‌ی فعلی روی GitHub Pages است، اجرای نصب‌کننده با همان دامنه میزبانی را از Pages به VPS منتقل می‌کند؛ پیش از چنین تغییری باید درباره‌ی DNS و معماری میزبانی تصمیم گرفت.

اطلاعات کارت، گذرواژه‌ی ادمین، کلید API و داده‌های مشتری نباید در مخزن عمومی ذخیره شوند. اطلاعات کارت در سورس عمداً خالی است؛ بعد از راه‌اندازی بک‌اند، آن را فقط از پنل خصوصی مدیریت تنظیم کن. داده‌های runtime داخل `server/data/` در `.gitignore` قرار دارند.
