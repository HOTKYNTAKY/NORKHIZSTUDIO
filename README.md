# ایران‌نگر — پروژه‌ی رسانه‌ی خبری

نسخه‌ی آماده‌ی نصب روی Linux داخل پوشه‌ی [`newsroom/`](newsroom/) قرار دارد. این پروژه یک وب‌سایت فارسی با پنل تحریریه، پایگاه‌داده‌ی پایدار، Docker Compose و TLS خودکار Caddy است. راهنمای نصب کامل در [`newsroom/README.md`](newsroom/README.md) است.

برای انتشار روی VPS، بسته‌ی `newsroom` را نصب کنید؛ فایل‌های ریشه‌ی مخزن هنوز مربوط به وب‌سایت قبلی VORTEXNET هستند و تا وقتی دامنه را به VPS منتقل نکرده‌اید، تغییری در میزبانی فعلی ایجاد نمی‌کنند.
