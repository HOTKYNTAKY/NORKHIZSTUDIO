# فریم ۱۸+ — فهرست فیلم بزرگسالان

نسخه‌ی فارسی و راست‌چین فریم برای نمایش فهرست محتوای بزرگسالان، با تأکید بر محدودیت ۱۸+، حقوق انتشار، سن قانونی و رضایت اجراکنندگان. رابط کاربری با طراحی اختصاصی Ultra Premium Glassmorphism، رنگ‌های نئونی بنفش/فیروزه‌ای، آیکون‌های SVG، پنل‌های شیشه‌ای، واکنش‌گرایی موبایل و پشتیبانی از `prefers-reduced-motion` پیاده‌سازی شده است. سایت اصلی به‌صورت static روی GitHub Pages اجرا می‌شود؛ منبع UI در `app/` و فهرست انتشار در `app/public/catalog.json` است.

## توسعه و انتشار

```bash
npm ci
npm run dev
```

ساخت خروجی نهایی Pages و کپی به ریشه‌ی مخزن:

```bash
npm run publish:pages
```

پس از انتشار تغییرات در شاخه‌ی Pages، فهرست عمومی از `catalog.json` خوانده می‌شود. دامنه‌ی `CNAME` حفظ می‌شود.

## افزودن عنوان به فهرست

می‌توانی عنوان، دسته، سال، توضیح کوتاه، پوستر HTTPS (اختیاری) و لینک HTTPS ویدئوی میزبان را برای من بفرستی تا فهرست مخزن را ویرایش و برای انتشار آماده کنم. فایل `catalog.json` باید آرایه‌ای از رکوردها باشد؛ نمونه‌ی فیلدها:

```json
{
  "id": "unique-id",
  "title": "عنوان",
  "type": "فیلم",
  "category": "داستانی",
  "year": 2026,
  "duration": "مدت",
  "description": "توضیح کوتاه",
  "video": "https://licensed-host.example/video.mp4",
  "poster": "https://licensed-host.example/poster.jpg",
  "rightsVerified": true,
  "performers18Plus": true,
  "consentVerified": true,
  "tone": "wine"
}
```

سایت فقط عنوان‌هایی را نشان می‌دهد که سه تأیید `rightsVerified`, `performers18Plus` و `consentVerified` را دارند و لینک ویدئوی HTTPS دارند. این فیلدها تأیید تحریریه‌اند، نه مدرک حقوقی یا احراز خودکار. برای هر مورد باید مجوز انتشار، بزرگسال‌بودن همه‌ی اجراکنندگان هنگام ضبط، و رضایت مستند و آگاهانه احراز شده باشد. محتوای افراد زیر سن قانونی یا با سن مبهم، غیررضایتی، افشاشده‌ی خصوصی یا قاچاق‌شده ممنوع است.

## محدودیت‌های میزبانی و سن

GitHub Pages فایل ایستا است: backend، حساب مدیر، آپلود ویدئو، گزارش‌دهی زنده یا ذخیره‌سازی مشترک ندارد. این نسخه **ویدئو میزبانی نمی‌کند**؛ پخش مستقیم فایل‌های سازگار از میزبان بیرونی HTTPS یا رفتن به لینک منبع را فراهم می‌کند. ویدئو را در GitHub یا مخزن عمومی قرار نده.

پنجره‌ی ورود ۱۸+ در این نسخه فقط خوداظهاری است و با sessionStorage در همان نشست مرورگر به خاطر می‌ماند؛ قابل دورزدن است و جایگزین احراز سن معتبر نیست. `robots.txt` دسترسی خزنده‌ها را محدود می‌کند، اما دسترسی عمومی را مسدود نمی‌کند. پیش از انتشار عمومی محتوای بزرگسال، قوانین کشور/بازار هدف (از جمله مقررات حفاظت از جوانان و احراز سن در محل فعالیت)، حریم خصوصی، شرایط میزبان ویدئو، فرایند مؤثر گزارش و حذف محتوا و راه تماس ناظر را با متخصص واجد صلاحیت بررسی و پیاده‌سازی کن. نسخه‌ی فعلی برای عرضه‌ی تجاریِ محتوای صریح آماده یا دارای تأیید حقوقی نیست.

## پوشه‌ی جداگانه

`newsroom/` نسخه‌ی مستقلی از پروژه‌ی پیشین تحریریه است و در سایت فریم استفاده نمی‌شود. اسکریپت پیوست‌شده‌ی قدیمی `vortexnet-setup-v30.sh` برای backend فروشگاه VORTEXNET است؛ برای این سایت اجرا یا به‌کار گرفته نشده است.
