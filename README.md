# گلیستا — فروشگاه آنلاین گل مصنوعی 🌿

فروشگاه کامل گل مصنوعی (باکس گل و دسته‌گل) با پنل مدیریت فارسی، طراحی لوکس و مینیمال، و **اسکریپت نصب خودکار صفر تا صد** برای سرور لینوکسی — آماده استقرار روی [golistahome.shop](http://golistahome.shop).

---

## ساختار محصولات

فروشگاه در نسخه فعلی **دو دسته اصلی** دارد و کل طراحی بر اساس همین دو دسته است:

| دسته اول: باکس گل | دسته دوم: دسته‌گل |
|---|---|
| باکس گل رز | دسته‌گل رز |
| باکس گل لاکچری | دسته‌گل عاشقانه |
| باکس گل عاشقانه | دسته‌گل لاکچری |
| باکس گل مناسب هدیه | دسته‌گل عروس |
| باکس گل ترکیبی | دسته‌گل ترکیبی |
| باکس گل سفارشی | دسته‌گل سفارشی |

- صفحه اصلی: دو **بخش بزرگ تصویری** (باکس گل / دسته‌گل) با عنوان، توضیح و دکمه «مشاهده محصولات» + ناحیه «محصولات ویژه».
- هر محصول: چند تصویر از زوایای مختلف (گالری)، نام، قیمت، قیمت تخفیف‌خورده، توضیحات، انتخاب رنگ (در صورت وجود)، انتخاب سایز (در صورت وجود)، انتخاب تعداد، وضعیت موجودی، دکمه علاقه‌مندی‌ها ♥ و افزودن به سبد خرید.
- سبد خرید + ثبت سفارش (پرداخت در محل / کارت به کارت) با کد پیگیری `GL-XXXXXX`؛ موجودی انبار خودکار کم می‌شود.

### قابلیت توسعه دیتابیس

دسته‌بندی‌ها در `server/data/db.json` با ساختار `parent` ذخیره می‌شوند:

- `parent: null` → دسته اصلی (کاندید نمایش در صفحه اصلی با فلگ `homeSection`)
- `parent: "box-flower"` → زیردسته

**اضافه کردن دسته اصلی جدید در آینده:** فقط یک ردیج جدید با `parent: null` — از پنل ادمین › «دسته‌ها» هم قابل انجام است؛ در نسخه فعلی فقط دو دسته «باکس گل» و «دسته‌گل» فلگ `homeSection` دارند و در صفحه اصلی نمایش داده می‌شوند.

## نصب خودکار روی سرور لینوکسی (صفر تا صد)

پیش‌نیاز: یک سرور لینوکسی تمیز (Ubuntu/Debian یا RHEL/Rocky/Alma) با دسترسی root و DNS دامنه که به IP سرور اشاره کند.

```bash
# ۱) دریافت کد
git clone https://github.com/HOTKYNTAKY/NORKHIZSTUDIO.git
cd NORKHIZSTUDIO

# ۲) نصب کامل — دامنه پیش‌فرض golistahome.shop است
sudo bash install.sh
```

اسکریپت به ترتیب انجام می‌دهد:

1. نصب/ارتقای Node.js 22 (در صورت نیاز)
2. انتقال فروشگاه به `/var/www/golistahome`
3. ساخت `server/.env` و پوشه دیتابیس `server/data` (chmod 700)
4. نصب و فعال‌سازی سرویس `golistahome-api` (systemd)
5. نصب Nginx + نوشتن vhost با دامنه موردنظر
6. باز کردن فایروال (فقط 80/443 — پورت API از بیرون بسته است)
7. دریافت خودکار گواهی HTTPS رایگان Let's Encrypt
8. سلامت‌سنجی و چاپ خلاصه (آدرس سایت و پنل ادمین)

### گزینه‌ها

```bash
sudo bash install.sh                          # golistahome.shop + HTTPS خودکار
sudo bash install.sh --ssl you@mail.com       # HTTPS با ایمیل مشخص
sudo bash install.sh --no-ssl                 # فقط HTTP
sudo bash install.sh --domain example.com     # دامنه دلخواه
sudo bash install.sh --port 9273              # پورت داخلی API
bash install.sh --help                        # راهنما
```

اجرای مجدد نصب **امن** است: دیتابیس و `server/.env` حفظ می‌شوند. به‌روزرسانی بعدی:

```bash
sudo bash update.sh
```

### بعد از نصب

| چیز | آدرس |
|---|---|
| فروشگاه | `https://golistahome.shop/` |
| پنل مدیریت | `https://golistahome.shop/admin` |
| سلامت API | `https://golistahome.shop/api/health` |
| لاگ سرویس | `journalctl -u golistahome-api -f` |
| فایل‌ها | `/var/www/golistahome` |
| دیتابیس | `server/data/db.json` |

**اولین ورود به پنل:** آدرس `/admin` را باز کنید → رمز مدیر را بسازید (نیازی به نام کاربری نیست). رمز فقط به‌صورت هش روی سرور ذخیره می‌شود.

## امکانات پنل مدیریت

- **محصولات:** افزودن/ویرایش/حذف در هر دو دسته، تغییر دسته، آپلود چند تصویر (کلیک/درگ‌انداز)، قیمت و تخفیف، موجودی (عدد / نامحدود / ناموجود)، محصولات ویژه، فعال/غیرفعال، **تغییر ترتیب نمایش** (▲▼)
- **دسته‌ها:** ساخت دسته اصلی یا زیردسته (در آینده دسته اصلی جدید همین‌جا ساخته می‌شود)، تصویر شاخص، توضیح، فلگ «بخش صفحه اصلی»، ترتیب
- **سفارش‌ها:** لیست، جزئیات، تغییر وضعیت (جدید/تأیید/ارسال/انجام/لغو) — لغو سفارش موجودی را برمی‌گرداند
- **تنظیمات:** نام و شعار فروشگاه، تلفن، آدرس، شبکه‌های اجتماعی، شماره کارت، هزینه ارسال، نوار اطلاعیه، تغییر رمز

## معماری و توسعه

```
shop/                    # فرانت‌اند استاتیک (بدون build — HTML/CSS/JS خالص، RTL)
  index.html             # صفحه اصلی: هیرو + دو بخش بزرگ + ویژه‌ها
  category.html          # لیست دسته/جست‌وجو/مرتب‌سازی/صفحه‌بندی
  product.html           # صفحه محصول: گالری، رنگ/سایز/تعداد، سبد خرید
  cart.html              # سبد خرید + فرم ثبت سفارش
  wishlist.html          # علاقه‌مندی‌ها (localStorage)
  assets/                # store.css (دیزاین‌سیستم) + store.js (هسته مشترک)
  fonts/ images/         # فونت وزیرمتن خودمیزبان + تصاویر محصولات
server/
  server.mjs             # API فروشگاه + پنل ادمین — Node صفر-وابستگی
  admin.html             # پنل مدیریت تک‌فایلی فارسی
  data/                  # db.json + نشست‌ها + آپلودها (gitignored)
deploy/
  nginx-site.conf        # کانفیگ Nginx (پروکسی /api, /admin, /uploads)
  golistahome-api.service# واحد systemd
install.sh update.sh     # نصب و به‌روزرسانی خودکار
```

- **بدون وابستگی npm** — نصب بدون `npm install`/build انجام می‌شود؛ خطای نصبِ وابستگی وجود نخواهد داشت.
- API نسخه توسعه: `node server/server.mjs` سرویس فرانت‌اند و API را با هم روی `http://localhost:9273` سرو می‌کند (همان چیزی که در پیش‌نمایش زنده می‌بینید).
- در سرور: Nginx استاتیک را مستقیم سرو می‌کند و فقط `/api/`، `/admin` و `/uploads/` را به Node پروکسی می‌کند؛ پورت API از بیرون باز نیست.

### افزودن محصول نمونه/جدید

از پنل ادمین (روش پیشنهادی) یا مستقیم با `PUT/POST /api/admin/products` با هدر `Authorization: Bearer <token>`.

## بخش قدیمی: سایت خبری ایران آزاد مدیا

این مخزن پیش‌تر میزبان وب‌سایت خبری «ایران آزاد مدیا» بود؛ کد تحریریه همچنان در `app/` و `newsroom/` حفظ شده و با همان دستور قبلی منتشر می‌شود:

```bash
npm ci
npm run dev            # توسعه
npm run publish:pages  # ساخت خروجی + انتشار در ریشه (GitHub Pages)
```

داده مطالب در `app/public/news.json` است (ساختار فیلدها در همان فایل و در commitهای قبلی توضیح داده شده). اسکریپت نصب/سرور قبلی فروشگاه VORTEXNET با کد فروشگاه گلیستا جایگزین شده و در تاریخچه مخزن باقی است.

## نکته

تصاویر محصولات نمونه تولیدشده برای نمایش اولیه‌اند؛ از پنل ادمین قابل جایگزینی با عکس‌های واقعی محصولات هستند.
