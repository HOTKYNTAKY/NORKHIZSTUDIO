# فریم — ویترین فیلم و سریال

وب‌سایت فارسی و راست‌چین معرفی فیلم و سریال، آماده‌ی انتشار به‌صورت سایت ایستا روی GitHub Pages. کد منبع قابل‌ویرایش در `app/` است؛ خروجی انتشار در ریشه‌ی مخزن قرار می‌گیرد و دامنه‌ی ثبت‌شده‌ی مخزن حفظ می‌شود.

## قابلیت‌ها

- صفحه‌ی سینمایی واکنش‌گرا، جست‌وجو، فیلتر نوع اثر و ژانر، کارت معرفی و پنجره‌ی پخش
- پنل نمایشی «مدیریت محتوا» برای افزودن، ویرایش، حذف، واردکردن و خروجی‌گرفتن از فهرست JSON
- پوسترهای گرافیکی جایگزین، بنابراین برای نمایش اولیه به فایل تصویری نیاز نیست
- پشتیبانی از لینک‌های HTTPS تریلر YouTube/Vimeo و فایل MP4 مستقیم

## توسعه و انتشار در GitHub Pages

```bash
npm ci
npm run dev
```

برای ساخت خروجی و کپی آن به ریشه‌ی مخزن:

```bash
npm run publish:pages
```

سپس تغییرات را در شاخه‌ی انتشار GitHub Pages کامیت و Push کنید. فایل‌های منبع UI در `app/` و فایل‌های سایت منتشرشده در ریشه و `assets/` هستند. دامنه‌ی `CNAME` دست‌نخورده باقی می‌ماند.

## محدودیت مهم پنل در سایت ایستا

GitHub Pages فقط فایل‌های ایستا را سرو می‌کند؛ بک‌اند، ذخیره‌سازی مشترک، آپلود فایل و احراز هویت مدیر ندارد. پنل فعلی یک ابزار ساده‌ی مرورگری است: تغییرات در `localStorage` همان مرورگر می‌ماند و به بازدیدکنندگان دیگر نشان داده نمی‌شود. از پنل «خروجی JSON» بگیرید و فایل دانلودشده را در مخزن جایگزین `app/public/catalog.json` کنید؛ سپس `npm run publish:pages` را اجرا و تغییرات را به GitHub پوش کنید. بعد از انتشار GitHub Pages، فهرست عمومی به‌روزرسانی می‌شود. این فرایند عمومی است و ویدئو را در GitHub آپلود نمی‌کند.

برای اعمال تغییرات عمومی از داخل یک پنل با دکمه‌ی انتشار، حساب مدیر امن و ذخیره‌سازی ویدئو، باید سرویس محتوایی/backend جداگانه (مثل CMS یا فضای میزبانی ویدئو) متصل شود. قرار دادن توکن GitHub یا رمز مدیر داخل JavaScript عمومی ناامن است و عمداً انجام نشده است. لینک ویدئو باید به اثری اشاره کند که اجازه‌ی انتشارش را دارید؛ فهرست فقط YouTube، Vimeo و MP4 روی HTTPS را پخش می‌کند.

## ساختار دیگر

پوشه‌ی `newsroom/` نسخه‌ی جداگانه‌ی پروژه‌ی قدیمی تحریریه است و سایت اصلی GitHub Pages نیست. فایل‌های سایت جدید از `app/` ساخته می‌شوند.
