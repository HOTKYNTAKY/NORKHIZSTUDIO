# ایران‌نگر — بسته‌ی خبرگزاری برای لینوکس

وب‌سایت خبری فارسی و راست‌چین با موضع تحریریه‌ی آشکار در حمایت از ایران سکولار و دموکراتیک و پادشاهی مشروطه. خبر، گزارش، تحلیل، دیدگاه و تاریخ برچسب‌های مجزا دارند؛ مطلب خبری منبع HTTPS می‌گیرد. خبرهای آغازین داخل پایگاه داده صرفاً نمونه‌اند و با نشان «نمونه‌ی آغازین» دیده می‌شوند؛ پیش از معرفی عمومی، آن‌ها را در پنل ویرایش یا حذف کنید.

## قابلیت‌ها

- صفحه‌ی اول واکنش‌گرا با دسته‌بندی، جست‌وجو، مطالب برجسته و خوراک RSS
- صفحه‌ی مستقل هر مقاله و منبع آن
- پنل تحریریه در `/admin`: ورود تک‌مدیر، پیش‌نویس/انتشار، ویرایش و حذف مطلب
- SQLite پایدار در `data/`، هش گذرواژه با scrypt، نشست تصادفی ۱۲ساعته و کوکی HttpOnly/SameSite
- محدودسازی تلاش ورود، بررسی Origin، Helmet/CSP و HTTPS خودکار Caddy
- نصب، به‌روزرسانی و پشتیبان‌گیری با Docker Compose

## نصب خودکار روی Ubuntu/Debian Linux

1. پیش از نصب، رکورد DNS دامنه را به IP سرور وصل کن. اگر دامنه روی GitHub Pages بوده، رکوردهای `A` را با IP سرور جایگزین کن. پورت‌های 80 و 443 باید باز باشند و در زمان صدور گواهی Cloudflare روی **DNS only** باشد.
2. روی سرور اجرا کن (بدون انتقال ZIP دستی):

```bash
curl -fsSL https://raw.githubusercontent.com/HOTKYNTAKY/NORKHIZSTUDIO/main/newsroom/install-online.sh | sudo bash
```

اسکریپت Docker و Compose را در Ubuntu/Debian نصب می‌کند، سورس عمومی را می‌گیرد و نصب را شروع می‌کند. نصاب دامنه، ایمیل گواهی و نام کاربری مدیر را می‌پرسد و گذرواژه را مخفی دریافت می‌کند؛ فقط هش در `.env` با دسترسی محدود ذخیره می‌شود. در پایان آدرس سایت و پنل (`https://YOUR_DOMAIN/admin`) چاپ می‌شود. این نصب‌کننده فعلاً Ubuntu و Debian را پشتیبانی می‌کند.

## نگه‌داری

```bash
sudo bash backup.sh    # پشتیبان سازگار از SQLite
sudo bash update.sh    # ساخت مجدد و راه‌اندازی نسخه‌ی تازه
```

پوشه‌ی `data/` شامل پایگاه داده‌ی مطالب و نشست‌هاست؛ آن را منظم به فضای پشتیبان خارج از VPS کپی کنید. `.env`، داده‌ها و نسخه‌های پشتیبان عمداً از مخزن Git و فایل نصب عمومی خارج هستند. پورت 3000 را روی فایروال عمومی نکنید؛ فقط SSH مدیریت‌شده و پورت‌های 80/443 لازم‌اند.

## انتشار و راستی‌آزمایی

خبرهای فوری یا نقل‌قول‌ها را با منبع اولیه و زمان انتشار وارد کنید. متن خام HTML پذیرفته نمی‌شود تا خطر XSS کاهش یابد. در پنل، از نوع «خبر» فقط برای داده‌ی قابل‌راستی‌آزمایی استفاده کنید و تحلیل/موضع تحریریه را با برچسب خودش منتشر کنید. راه تماس عمومی در صورت واردکردن ایمیل در زمان نصب نمایش داده می‌شود.
